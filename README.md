# Data Analytics Assignments

This repository contains projects and assignments completed for a graduate-level Data Analytics Seminar. It serves as a portfolio and archive of coursework exploring how data can be prepared, analyzed, visualized, and communicated to support informed decision-making.

## Repository Contents

Projects will be added throughout the course and may include:

- Data cleaning and preparation
- Exploratory data analysis
- Statistical analysis
- Data visualization
- Predictive modeling
- Written interpretations and recommendations

Each project will be stored in its own directory with the relevant source code, data documentation, and supporting materials.

## Purpose

The work collected here demonstrates the practical application of data analytics concepts developed during graduate study. This repository will continue to evolve as projects are completed and refined.
